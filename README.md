# 词间 · 六级记忆助手

**在线使用：https://qslg.github.io/cet6-assistant/**

手机、电脑直接打开即可使用，无需安装 App。

- 5,803 张词卡：高中基础、六级进阶与关联补充；保留 1,129 词精选学习池。
- 英美发音、隐藏中文自测、按序展开释义。
- 近义关联、形近辨析、118 条短语、479 组词形联结。
- 强化记忆本、复习安排、导入与导出备份。

学习记录保存在各设备的浏览器内，不会上传到 GitHub，也不会自动跨设备同步。
换设备前请导出备份，在另一设备导入。从原 localhost 网站迁移也需导出、导入一次。
发音需要联网；浏览器语音可用时作为后备。

词库的释义顺序与阅读精选属于学习整理，并未以完整真题语料统计实际考频。

## 源码与更新

下载 [完整源码包](./cet6-assistant-source.zip)，解压后使用 Node.js 22.13 或更新版本：

```sh
npm ci
npm run dev
npm run check
npm run build
```

构建结果在源码包的 `docs/` 目录。将该目录中的网页文件上传到这个仓库的根目录即可更新。
GitHub Pages 发布源为 `main` 分支、根目录 `/`。
源码包没有原始电子书、账号凭据或个人学习记录。
